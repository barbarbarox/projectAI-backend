Ancaman Cyber Meningkat

Peningkatan pesat serangan siber (seperti Phishing & Malware) yang menargetkan kerentanan sistem web dan kurangnya edukasi publik mengenai keamanan data.

AI Hallucination & Data Leak

Model AI publik rentan terhadap prompt injection dan sering memberikan informasi fiktif (halusinasi) atau membocorkan konteks sensitif sistem.

Solusi RedSim: Sebuah sistem cerdas berbasis Retrieval-Augmented Generation (RAG) yang membatasi konteks AI hanya pada keamanan sistem dan memiliki fitur analisis URL/sistem secara aman.

Tujuan & Manfaat

  • Otomatisasi Analisis Keamanan: Memfasilitasi deteksi kerentanan URL dan sistem berbasis pemindai terintegrasi (VirusTotal/URLScan).
  • Isolasi Data AI (RAG): Menyediakan asisten AI yang cerdas namun terisolasi (tidak membocorkan data luar atau prompt asli) berkat teknologi Vector Database Pinecone.
  • Keamanan Autentikasi: Memastikan akses hanya untuk pengguna sah melalui verifikasi dua langkah (OTP WhatsApp via Fonnte) & validasi reCAPTCHA.
  • Edukasi Interaktif: Menawarkan modul Leaderboard dan tantangan (CTF ringan) untuk mengedukasi pengguna tentang keamanan web.

Arsitektur Sistem & Basis Data

Sistem dibangun dengan arsitektur modern yang memisahkan komputasi AI, manajemen RDBMS, dan Vector Storage.

  • Backend: Laravel 11 (PHP 8.2)
  • Basis Data Utama: PostgreSQL (Supabase)
  • Basis Data Vektor: Pinecone
  • AI Provider: Groq (LLaMA 3.3) / NVIDIA NIM

Alur Kerja Pengguna (User Flow)

  • Registrasi Aman: Pendaftaran akun dengan validasi email/WhatsApp. Akun dari Google OAuth akan ditahan untuk verifikasi nomor WhatsApp secara manual oleh Admin.
  • Proses Otentikasi: OTP dikirim via WhatsApp Fonnte untuk validasi sesi.
  • Analisis URL: Pengguna menginput URL, diproses melalui sistem antrean (Queue) Laravel secara background.
  • Laporan Keamanan: Pengguna menerima laporan format PDF (Dompdf) atau langsung berkonsultasi dengan Asisten AI terkait hasil analisis.

Implementasi Keamanan Basis Data

  • Parameter Binding & ORM: Menggunakan Eloquent ORM Laravel secara menyeluruh untuk memitigasi serangan SQL Injection.
  • Enkripsi Data: Kata sandi menggunakan hashing Bcrypt (12 Rounds). Data sesi (Session) dan cache diproteksi.
  • API Gateway Security: Pembatasan jumlah request ke API pihak ketiga (Groq/NVIDIA) untuk mencegah serangan Denial of Wallet (DoW) / pengurasan kuota API token AI.
  • Keamanan Prompts AI: Penggunaan System Prompt ketat yang menolak modifikasi instruksi, menjaga AI dari jailbreak dan kebocoran logika internal sistem.

Skema Basis Data (ERD)

Struktur tabel pada Supabase PostgreSQL mengutamakan integritas relasional data.

  • Tabel Users: Pengguna & Admin (RBAC).
  • Tabel Scan_Histories: Melacak aktivitas pemindaian.
  • Tabel Ai_Configurations: Pengaturan rotasi token API AI dinamis (menghindari hardcode).
  • Tabel Edukasi: Soal tantangan (CTF) dan progres pengguna.

Pengujian Keamanan Sistem

Hasil pengujian teknis pada sistem menunjukkan performa dan resiliensi yang sangat baik:

Uji Autentikasi

Validasi nomor WA dan OTP berhasil memblokir bot/spam. Sistem pendaftaran SSO (Google) berhasil dikunci hingga divalidasi admin.

Uji Keamanan AI

Uji injeksi prompt gagal menembus batas RAG. AI secara konsisten menjawab dalam koridor keamanan siber dan tidak memberikan jawaban di luar topik.

Kesimpulan

  • RedSim berhasil diimplementasikan sebagai alat edukasi dan simulasi keamanan siber yang komprehensif.
  • Penggunaan arsitektur RAG yang digabungkan dengan integrasi model besar (seperti LLaMA 3.3 via Groq) mempercepat respons tanpa mengorbankan privasi data lokal.
  • Sistem autentikasi yang diawasi (verifikasi manual WhatsApp) menjamin keamanan platform dari penyalahgunaan.
  • Pengembangan ke Depan: Otomatisasi notifikasi hasil scanning dan penambahan lebih banyak modul Machine Learning lokal.
